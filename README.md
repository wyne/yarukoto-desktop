# Yarukoto for Mac and Windows

Downloads for the [Yarukoto](https://yarukotoapp.com) desktop apps. Yarukoto is a self-hosted todo app, so you'll also need a [Yarukoto server](https://docs.yarukotoapp.com/getting-started/docker/) to connect to.

- **Mac:** [Yarukoto-mac.dmg](https://github.com/wyne/yarukoto-desktop/releases/latest/download/Yarukoto-mac.dmg). Open it and drag Yarukoto to Applications. It's signed and notarized by Apple.
- **Windows:** [Yarukoto-windows-setup.exe](https://github.com/wyne/yarukoto-desktop/releases/latest/download/Yarukoto-windows-setup.exe), or the [.msi](https://github.com/wyne/yarukoto-desktop/releases/latest/download/Yarukoto-windows.msi). The installer isn't signed yet, so the first time it runs Windows shows "Windows protected your PC": choose **More info**, then **Run anyway**.

Every version, with checksums, is on the [releases page](https://github.com/wyne/yarukoto-desktop/releases).

This repo holds no code. The source, issues and documentation live in [wyne/yarukoto](https://github.com/wyne/yarukoto), and its Desktop release workflow publishes the releases here.
